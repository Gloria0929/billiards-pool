# 真实台球 3D · 联机版

把原来 1.6 MB 的单文件 HTML（内联 Three.js、物理、规则、音效）拆成了 Vue 3 + Vite 项目，并加入了人机对战与联网对战。

## 运行

```bash
npm install
npm run dev:all
```

打开 http://localhost:5173 。`dev:all` 会同时启动：

- Vite 前端（5173）
- 联机服务（3210，前端通过 Vite 代理访问 `/ws`）

只启动其中一部分：

```bash
npm run dev      # 仅前端，人机对战可玩
npm run server   # 仅联机服务
```

## 生产部署

```bash
npm run build
npm start
```

`npm start` 会在 3210 端口同时提供构建后的静态页面和 WebSocket 服务（同源 `/ws`）。可用 `WS_PORT` 改端口：

```bash
WS_PORT=8080 npm start
```

## 人机对战

1. 菜单选择「人机对战」，挑中式八球或斯诺克后开始，你执先手、电脑执后手。
2. 开局前可以在「电脑难度」里选择简单 / 普通 / 困难，选择会被记住；游戏中的标题栏也会显示当前难度。困难电脑进球率更高，会用加塞和高低杆控制白球走位。
3. 你击球结束后，电脑会自动选球、瞄准并击球；轮到电脑时你的击球和力度控件会锁定，视角仍可自行调整。
4. 辅助线会显示目标球线和一条虚线翻袋/反弹线路：蓝色虚线是白球的翻袋线路，金色虚线是目标球的翻袋线路；若线路能进袋，袋口会出现同色圆环提示。
5. 每局结束后会进入结算面板：可以选择下一局（单局则为再来一局），或退出回到首页。

## 联机对战

1. 菜单切换到「游戏大厅」标签页，会自动连接并展示所有公开房间；也可以切到「联网对战」创建房间或输入房间码。
2. 房主填昵称，在创建卡片里选择玩法（中式八球 / 斯诺克）、房间类型、辅助线开关和赛制（单局 / 三局两胜 / 五局三胜 / 七局四胜），点「创建房间」得到 5 位房间码。
   - **公开房间**会出现在大厅列表，其他玩家点「申请加入」后需要房主同意；房主会看到申请并选择同意或拒绝。
   - **私有房间**不会出现在大厅，凭 5 位房间码直接加入。
3. 另一位玩家填写昵称并输入房间码加入；公开房间即使知道房间码，也会走房主审批。
4. 房主点「开始比赛」。之后只有轮到的玩家能瞄准、摆球和击球；辅助线开关以房主创建房间时的设置为准。
5. 非击球方的视角会实时跟随击球方：能看到对方当前的视角、瞄准方向、力度、球杆蓄力和自由球摆位，而不是停在固定画面。
6. 每局结束后进入结算：双方都点「下一局」后进入下一局；一方达到赛制所需胜场后，双方都点「再来一场」则开始新一场比赛。对手离开或房主离开会提示并关闭/返回大厅。

联机采用**服务端权威**：客户端只上报击球参数（角度、力度、旋转、自由球位置），服务器用同一套物理与规则模拟到静止，再把权威状态广播给双方。客户端本地也会播放同一杆的动画，结束后对齐服务器状态，避免两端物理漂移。

## 说明

- 中式八球：开球保持开放，开球后的合法首碰球组有球落袋时才定组。清完本组再合法打进 8 号球获胜，黑八无需报袋。开球按旧版乔氏四球次过线计数，目标球达到半球越线或入袋各计一次，先越线再入袋计两次；未达标判失机，对手可接打或选任一方重开。整场每累计三次失机判负一局，每局轮换开球方。开球犯规可选线后自由球或重开，合法开球进黑八可复位续打或重开。无球入袋时必须在撞球后有球碰库。
- 瞄准辅助：直球可以直接瞄袋口；切球要瞄白球碰到目标球时的半透明「幽灵球」，让金色目标线指向袋口。目标线对准袋口时袋口会出现金色圆环。不加塞时线路与实际落点一致，加塞会让目标球带偏，需要自行修正瞄准。
- 力度：开球时默认满力；人机 / 联机对手的瞄准力度只用于显示，不会覆盖你自己的力度，回到你的回合会恢复你上次设置的力度。开球物理经过调优（开球加成、球间弹性），满力正对球堆约八成以上能满足四球次过线；改动开球手感后可以跑 `npm run bench:break` 回归。
- 人机对战的电脑在没有直接线路时会尝试借库解球，避免一直先碰到挡路的球。
- 每局摆球会按随机种子带一点整体旋转、整体偏移、球位误差和球体质量 / 摩擦差异，联网双方仍一致；开球后的球型不再每局雷同。
- 斯诺克：红彩交替，进红后选择目标彩球。彩球原位被占时优先摆到分值最高的空彩球点。最后一颗红球合法入袋后可再打一次彩球，最后一红随犯规离台后从黄球开始清彩。
- 斯诺克犯规后，对手可自己打或让犯规方从留位打，判 Miss 时还可要求回原位打。三次判负仅用于可直接打满球或符合贴球条件的原位重打序列。
- 斯诺克自由球：犯规后判定被斯诺克时，可选一颗彩球替代目标球。手中球要检查 D 区的可用摆位。自由球按目标球计分并复位，清彩阶段只进替代球时还要再打原目标球。
- 斯诺克抢黑：清台后同分重摆黑球，抽签选先后手，从 D 区开始。仅余黑球且领先超过 7 分时结算。落后方需要罚分追分时，可在自己回合提出认输，联机对手可接受或继续打。
- 僵局重摆：联机可在自己回合提出重摆，对手同意后由原开球方重开。人机连续六杆无进球或罚分时可重摆。
- 音效为原文件内嵌的实录音频（光厂），仅供个人非商业学习、研究与交流使用。
- 一个房间两名玩家，房间码 5 位；不保存历史战绩，服务端为内存房间。
